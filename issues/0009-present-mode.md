# Present mode and rehearsed golden path

**Type:** HITL
**Blocked by:** #0006, #0007
**PRD:** `PRD.md`

## What to build

A present mode that sets a named real scenario through the same URL state a human would use: Times Square to a Brooklyn destination, Saturday 23:00. Keyboard control advances the five-minute script. No fabricated data and no bypassed API. Rehearse the script twice end to end and record what failed.

## Acceptance criteria

- [ ] Present mode changes only real UI state; every number still comes from the API.
- [ ] The five-minute script runs without manual fixes twice in a row.
- [ ] The 03:00 hour change visibly alters the risk surface and route result.
- [ ] Worst-segment explanation is reachable in two interactions.
- [ ] Method screen can be opened and closed without losing route results.
- [ ] The demo runs at 1280×720 and 1920×1080.
- [ ] A presenter can recover from one unavailable live source mid-demo.
